# 기안문 JSON 형식

`scripts/build_gongmun.py`가 읽는 파일입니다. 예시: `examples/sample_science_club.json`(지어낸 학교·숫자).

| 칸 | 꼭 | 뜻 |
|---|---|---|
| `school` | ✔ | 학교 이름. 종이 머리에 크게 나옵니다. |
| `title` | ✔ | 제목. 끝에 마침표를 찍지 않습니다. |
| `lead` | ✔ | `2.` 뒤에 오는 본문 첫 문장. 번호는 쓰지 않습니다. |
| `receiver` | | 수신. 내부결재면 `"내부결재"`. |
| `via` | | (경유). 없으면 빈 글자. |
| `slogan` | | 종이 맨 위 표어. |
| `kind` | | 화면 위에 작게 나오는 문서 종류(예: `"지출 품의 · 내부결재"`). |
| `written` | | 작성일 `2026-11-04`. 연도가 없는 날짜의 요일을 검사할 때 씁니다. |
| `related` | | 관련 문서 목록: `{doc_no, date, title, source}`. 모르는 값은 `"[확인 필요]"`. |
| `items` | | 본문 항목 나무: `{text, children}`. 깊이마다 가. → 1) → 가) → (1)이 붙습니다. |
| `attachments` | | 붙임: `{name, count, ready}`. `ready: false`면 확인으로 표시합니다. |
| `approval` | | 결재선: `{role, name}`. 이름은 `학교설정.json`에서 가져오고, 저장소 예시에는 넣지 않습니다. |
| `cooperation` | | 협조자: `{role, name}`. |
| `footer` | | 시행 줄: `{doc_no, address, phone, fax, disclosure}`. 쓴 칸만 나옵니다. |
| `ledger` | | 예산 장부: `{name, allocated, basis, basis_doc, spend: [{name, amount}]}`. `name`이 본문 항목 `이름: 금액`의 이름과 같으면 금액을 맞춰 봅니다. |
| `todo` | | 상정 전에 볼 것(문장 목록). |
| `links` | | 함께 볼 자료: `{label, url}`. 학생 사진이 있는 곳은 넣기 전에 공개 범위를 확인합니다. |
| `page_title` | | 아티팩트 이름(2~4낱말). 비우면 제목 앞 30자. |
| `example` | | `true`면 화면에 "예시 자료"라고 표시합니다. |

## 금액을 쓰는 법

- 산출식: `3,000원*12모둠=36,000원`. `*` 대신 `×`도 됩니다. `=` 뒤의 값을 곱셈으로 맞춰 봅니다.
- 소계: `실험 재료비: 156,000원`처럼 `이름: 금액`으로 쓰고, 아래 `children`에 산출식을 둡니다.
- 소요예산: `소요예산: 금246,000원(금이십사만육천원)`. `산출내역`으로 시작하는 항목 아래 전체 합과 맞춰 봅니다.
