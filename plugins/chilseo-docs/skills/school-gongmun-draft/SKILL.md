# 학교 기안문 → 종이 모양 화면

선생님이 에듀파인에 올리기 전 기안문을 한 화면에서 보고, 제목과 본문을 바로 복사해 붙여 넣을 수 있게 한다.
이 스킬의 원칙은 하나다. **지어낸 숫자·문서번호·이름은 하나도 넣지 않는다.**

이 스킬 폴더는 `${CLAUDE_SKILL_DIR}`다. 값이 채워지지 않는 환경(Claude 앱 등)에서는 이 SKILL.md가 있는 폴더를 쓴다. 아래에서 `$S`는 그 폴더다.

## 꼭 지킬 것

1. **지어내지 않는다.** 관련 문서번호·시행일·편성액·인원·단가는 선생님이 준 자료에서만 가져온다. 모르면 `[확인 필요]`로 두고 화면에서 눈에 띄게 한다.
2. **질문은 만들기 전에 한 번에 모은다.** 빠진 값을 한 번에 묻고, 답을 받은 뒤 만든다. 답이 없는 값은 `[확인 필요]`로 남긴다.
3. **개인정보를 넣지 않는다.** 학생 이름·연락처·상담 내용은 본문에도 화면에도 넣지 않는다. 대상은 "참가 학생 2명(5학년 1명, 6학년 1명)"처럼 인원으로 쓴다.
4. **공문 원문을 옮겨 적지 않는다.** 관련 문서는 기관·문서번호·날짜·제목만 쓴다.
5. **검사를 통과해도 상정은 선생님이 한다.** "결재 올리면 된다"고 말하지 않는다. 확인할 곳과 상정 전에 볼 것을 함께 알린다.

## 0. 처음 쓸 때 (한 번만)

작업 폴더에 `학교설정.json`이 있으면 읽는다. 없으면 아래를 한 번에 묻고 저장한다. 모양은 `$S/assets/school-settings.example.json`이다.

1. 학교 이름, 종이 맨 위 표어(없어도 됨)
2. 결재선: 기안자 직위, 검토·결재자 직위와 이름, 협조자
3. 시행 줄에 넣을 학교 주소·대표 전화·공개 구분(넣지 않아도 됨)

- 이름과 전화는 선생님 컴퓨터의 `학교설정.json`에만 둔다. 이 스킬 폴더나 공개 저장소에 쓰지 않는다.
- Claude 앱처럼 파일이 남지 않는 곳에서는 "프로젝트 지침에 학교 이름과 결재선을 적어 두면 다음에 다시 묻지 않는다"고 안내한다.

## 1. 원고 읽기

선생님이 준 계획서·노션 페이지·결재 PDF·메모에서 아래를 찾는다.

- 제목, 수신(내부결재가 대부분), 관련 문서(번호·날짜·제목)
- 본문 첫 문장("…을 아래와 같이 지출하고자 합니다.", "…을 붙임과 같이 보고합니다.")
- 항목(용도·대상·기간·소요예산·산출내역·예산과목 등)
- 붙임과 준비 여부, 예산 편성액과 근거 문서

## 2. JSON 쓰기

형식은 `references/input-format.md`, 예시는 `examples/sample_science_club.json`이다.

- 번호는 쓰지 않는다. 스크립트가 1. 가. 1) 가) (1)과 붙임·"끝."을 붙인다.
- 산출식은 `3,000원*12모둠=36,000원`, 소계는 `실험 재료비: 156,000원`, 소요예산은 `소요예산: 금246,000원(금이십사만육천원)`으로 쓴다.
- 결재선 이름은 `학교설정.json`에서 가져온다.

## 3. 검사하고 화면 만들기

```bash
python3 "$S/scripts/build_gongmun.py" 기안.json -o 기안문.html
```

검사 규칙은 `references/rules.md`에 있다. 결과는 세 가지다.

- **고침**이 하나라도 있으면 화면을 만들지 않는다. JSON을 고쳐 다시 돌린다. 계산이 틀린 곳은 선생님께 어느 숫자가 맞는지 묻는다.
- **확인**은 화면에 표시하고, 상정 전에 채울 것으로 알린다.
- Python을 쓸 수 없는 곳이면 검사 없이 화면을 만들지 않는다. 대신 본문을 글로 보여 주고 계산을 직접 검산해 함께 알린다.

## 4. 보여 주기

- **아티팩트를 만들 수 있으면 아티팩트로 올린다.** Claude Code에서는 Artifact 도구로 `기안문.html`을 게시한다. Claude 앱에서는 `기안문.html` 내용을 그대로 HTML 아티팩트로 만든다.
- 아티팩트를 만들 수 없으면 `기안문.html` 파일을 건넨다. 브라우저로 열면 같은 화면이 나온다.
- 화면 모양(`assets/gongmun.html`)은 고치지 않는다. 어느 선생님이 써도 같은 모양이 나오게 하기 위해서다.
- 학생 사진이 있는 노션 링크를 `links`에 넣을 때는 공개 범위를 먼저 확인해 달라고 말한다.

넘길 때 함께 말한다: 검사 결과(통과·확인·고침 수), `[확인 필요]`로 남긴 것, 상정 전에 볼 것.

## 화면 구성

1. 종이 모양 시행문: 표어, 학교 이름, 수신·(경유)·제목, 본문, 결재선, 시행 줄
2. 에듀파인용 "제목 복사하기"·"본문 복사하기" 버튼. 화면의 내어쓰기는 CSS로만 해서, 끌어 골라 복사해도 번호와 내용이 한 줄로 붙는다.
3. 예산 장부: 편성액 → 이번 집행 → 잔액, 집행률 막대 (`ledger`가 있을 때)
4. 검사 결과 칩
5. 상정 전에 볼 것 (`todo`가 있을 때)
