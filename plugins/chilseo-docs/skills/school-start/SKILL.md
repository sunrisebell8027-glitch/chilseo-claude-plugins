# 시작하기: 준비물 확인 → 학교 설정 → 첫 부탁

처음 쓰는 선생님이 10분 안에 첫 문서를 만들 수 있게 한다. 한 번에 한 가지만 묻고, 설치하기 전에는 무엇을 왜 설치하는지 한 줄로 말하고 허락을 받는다.

이 스킬 폴더는 `${CLAUDE_SKILL_DIR}`다. 값이 채워지지 않는 환경에서는 이 SKILL.md가 있는 폴더를 쓴다. 아래에서 `$S`는 그 폴더다.

## 꼭 지킬 것

1. **쉬운 말로 말한다.** "가상환경", "패키지", "PATH" 같은 말은 쓰지 않거나 한 줄로 풀어 쓴다. 예: "문서를 만드는 데 필요한 부품 두 개를 선생님 컴퓨터의 작은 폴더(`~/.chilseo`)에 넣어 둘게요."
2. **설치는 허락을 받고 한다.** 무엇을, 어디에, 왜 넣는지 말하고 "해도 될까요?"라고 묻는다. 거절하면 그 기능 없이 할 수 있는 것을 알려 준다.
3. **이름·전화는 `학교설정.json`에만 둔다.** 이 스킬 폴더, 플러그인 폴더, 공개 저장소에 쓰지 않는다. 저장한 뒤 "이 파일은 선생님 컴퓨터에만 있어요"라고 알린다.
4. **한 번에 하나씩 묻는다.** 준비물 → 학교 설정 → 첫 부탁 순서로 간다. 이미 된 단계는 건너뛴다.
5. **끝에는 할 수 있는 일 하나를 제안한다.** 목록만 늘어놓지 않고 "지금 바로 ○○부터 해 볼까요?"로 맺는다.

## 1. 준비물 확인

```bash
python3 "$S/scripts/setup_env.py" --check
```

- Windows에서 `python3`가 없으면 `python` 또는 `py -3`으로 바꿔 실행한다.
- 출력을 읽고 선생님께 쉬운 말로 전한다. 현재 Python과 준비 폴더에 문서 도구가 있는지, 선택 사항인 Node.js가 있는지와 다음 할 일이 나온다.
- 종료 코드 0이면 현재 Python 또는 준비 폴더에 두 도구가 모두 있다는 뜻이다. 같은 Python으로 문서 스크립트를 실행하고 3단계로 간다. 종료 코드 1이면 설치가 필요하므로 허락을 받고 2단계로 간다. 종료 코드 2이면 출력된 오류를 안내한다.

**Python이 아예 없으면** 스크립트도 돌지 않는다. 이렇게 안내한다.

- Windows: https://www.python.org/downloads/ 에서 최신 Python 3를 받아 설치한다. 설치 첫 화면에서 **"Add python.exe to PATH"** 를 꼭 켠다. 또는 허락을 받고 `winget install Python.Python.3.12`를 실행한다.
- Mac: 허락을 받고 `brew install python`을 실행한다. Homebrew가 없으면 python.org 설치 파일을 쓴다.
- 설치가 끝나면 Claude Code를 다시 시작하고 1단계를 다시 한다.

## 2. 없는 것 설치하기

```bash
python3 "$S/scripts/setup_env.py"
```

- Windows에서는 1단계에서 사용한 `python` 또는 `py -3`을 같은 방식으로 쓴다.
- 현재 Python이나 준비 폴더에 두 도구가 이미 있으면 설치하지 않는다. 그렇지 않으면 `~/.chilseo/venv`에 lxml과 python-hwpx를 설치한다. 권한이나 인터넷 설정에 따라 설치가 막힐 수 있다.
- `CHILSEO_HOME`을 설정하면 그 폴더의 `venv`를 쓰고, 비어 있으면 `~/.chilseo/venv`를 쓴다. `--home`으로 지정한 폴더가 가장 우선이다. 문서 스크립트에서도 같은 위치를 찾으려면 `CHILSEO_HOME`을 같은 값으로 설정한다.
- 문서 스킬(`school-plan-hwpx`, `school-newsletter`)의 스크립트는 패키지가 없으면 이 준비 폴더를 알아서 찾아 쓴다. 선생님이 따로 할 일은 없다. 설치가 끝나면 종료 코드 0이고, 설치 또는 확인에 실패하면 1이다. 예상하지 못한 확인 오류는 2다.
- 실패하면 출력의 안내를 그대로 전한다. 인터넷이 막힌 곳이면 "학교 정보 담당자에게 python.org와 pypi.org 접속을 요청해 달라"고 말한다.
- **Node.js가 없으면**: 한글 파일을 그림으로 미리 보는 도구(kordoc)만 못 쓴다. 문서 만들기는 된다. 원하면 https://nodejs.org 에서 LTS를 설치하고 Claude Code를 다시 시작하라고 안내한다. Windows는 허락을 받고 `winget install OpenJS.NodeJS.LTS`, Mac은 `brew install node`도 된다.

## 3. 학교 설정 한 번만

작업 폴더에 `학교설정.json`이 있으면 읽는다. 없으면 `~/.chilseo/학교설정.json`을 읽는다. 둘 다 없으면 아래를 **하나씩** 묻는다. 이미 있는 파일은 빠진 칸만 채우고, 다른 스킬이 쓰는 칸은 지우지 않는다.

1. 학교 이름 (예: 칠서초등학교)
2. 계획서·가정통신문 양식: 칠서초등학교면 기본 양식을 쓴다. 다른 학교면 "예전에 결재한 계획서와 가정통신문 한글 파일을 하나씩 주시면 우리 학교 양식으로 만들어 드려요"라고 말하고, 그 일은 각 문서 스킬에서 한다.
3. 기안문 결재선: 기안자 직위, 검토·결재자 직위와 이름(보통 교감·교장), 협조자(보통 행정실장)
4. 학교 대표 전화 두 개(교무실·행정실)와 누리집 주소, 우편번호와 주소 (모르면 비워 두고 `[확인 필요]`)

저장 모양은 이렇다. 작업 폴더에 저장하고, 선생님이 여러 폴더에서 쓰겠다고 하면 `~/.chilseo/학교설정.json`에 저장한다.

```json
{
  "school": "○○초등학교",
  "slogan": "종이 맨 위 표어 (없으면 빈 글자)",
  "template": "chilseo_plan_template.hwpx",
  "approval": [
    {"role": "연구부장", "name": "처음 쓸 때 입력"},
    {"role": "교감", "name": "처음 쓸 때 입력"},
    {"role": "교장", "name": "처음 쓸 때 입력"}
  ],
  "cooperation": [{"role": "행정실장", "name": "처음 쓸 때 입력"}],
  "masthead": {"phones": ["교무실 대표 번호", "행정실 대표 번호"], "homepage": "학교 누리집 주소"},
  "footer": {"address": "우편번호와 학교 주소", "phone": "학교 대표 전화", "fax": "학교 전송", "disclosure": "공개 구분"}
}
```

- `school`·`template`은 계획서 스킬, `school`·`masthead`는 가정통신문 스킬, `school`·`slogan`·`approval`·`cooperation`·`footer`는 기안문 스킬이 쓴다.
- 교직원 개인 전화번호는 받지 않는다. 학교 대표 번호만 쓴다.
- 저장한 위치를 알려 주고 "이 파일은 선생님 컴퓨터에만 있어요. 저장소나 다른 곳에는 올라가지 않아요"라고 말한다. 공유 폴더나 git 저장소 안이면 다른 곳을 권한다.

## 4. 무엇을 부탁할 수 있는지 보여 주기

표 한 개와 예시 세 개까지만 보여 주고, 하나를 골라 바로 해 보자고 제안한다.

| 이렇게 말하면 | 만들어 드리는 것 |
|---|---|
| "○○ 운영 계획서를 학교 양식 한글 파일로 만들어 주세요" | 내부결재용 계획서(HWPX), 예산·요일 검산 |
| "○○ 지출 품의 기안문을 만들어 주세요" | 에듀파인에 붙여 넣을 제목·본문, 예산 장부, 검산 결과 |
| "○학년 ○○ 체험학습 가정통신문을 만들어 주세요" | 학교 양식 가정통신문(HWPX)과 보호자용 미리보기 |
| "○○ 사업 보드를 만들어 주세요. 무엇부터 해야 해요?" | 필요한 문서와 지금 할 일·다음 할 일이 담긴 보드 |

첫 부탁 예시:

- "3학년 박물관 체험학습 가정통신문을 만들어 주세요. 12월 9일 수요일 9시부터 3시까지, 준비물은 도시락·물·편한 신발이고, 동의서는 12월 2일까지 받아요."
- "아래 원고로 겨울 독서 주간 운영 계획(안) 한글 파일을 만들어 주세요. 모르는 값은 채우지 말고 먼저 물어봐 주세요. (원고 붙여 넣기)"
- "과학 탐구 동아리 사업 보드를 만들어 주세요. 무엇부터 해야 할지 알려 주세요."

함께 알린다.

- 학생 이름·연락처·상담 내용은 넣지 않는다. 명단이 필요하면 빈 칸 표로 만든다.
- 만든 한글 파일은 꼭 한글에서 열어 쪽 나눔을 확인한다.
- 모르는 값은 지어내지 않고 `[확인 필요]`로 남긴다.

## 막혔을 때

| 현상 | 하는 일 |
|---|---|
| `python3: command not found`, `'python'은(는) 내부 또는 외부 명령...` | 1단계의 Python 설치 안내. Windows는 PATH 켜기. |
| `externally-managed-environment` | 정상이다. 2단계 스크립트가 `~/.chilseo/venv`에 따로 넣는다. |
| `pip`가 멈추거나 `Connection` 오류 | 학교 인터넷이 막은 것일 수 있다. 정보 담당자에게 python.org·pypi.org 접속을 요청하라고 안내한다. |
| kordoc이 도구 목록에 없음 | Node.js를 설치하고 Claude Code를 다시 시작한다. 없어도 문서 만들기는 된다. |
| 스킬이 반응하지 않음 | Claude Code를 다시 시작하고 `/plugin list`로 `chilseo-docs`가 있는지 본다. 부탁에 "가정통신문", "계획서"처럼 문서 이름을 넣으라고 알린다. |
