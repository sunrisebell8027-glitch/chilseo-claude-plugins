# 가정통신문 JSON 형식

`scripts/build_newsletter.py`가 읽는 파일입니다. 예시: `examples/sample_museum_trip.json`(지어낸 행사).

| 칸 | 꼭 | 뜻 |
|---|---|---|
| `school` | ✔ | 학교 이름. 양식 머리말의 학교 이름과 같아야 합니다. |
| `title` | ✔ | 제목 상자에 들어갈 제목. 60자 이내로 씁니다. |
| `items` | ✔ | 구분/내용 표의 줄: `{label, text}`. `label`은 왼쪽 칸(일시·장소…)이며 20자 이내로 씁니다. `text`는 오른쪽 칸입니다. `text`에 `\n`을 넣으면 칸 안에서 줄을 나누고 칸 높이가 늘어납니다. |
| `summary` | ✔ | 보호자가 맨 위에서 볼 것: `when`(꼭), `bring`(목록), `reply_by`(회신서가 있으면 꼭). |
| `greeting` | | 인사말 문단 목록. |
| `items_title` | | 표 위 제목. 비우면 `< 안내 내용 >`. 예: `< 체험활동 내용 >` |
| `notes` | | 표 바로 아래 ※ 알림 목록. `※`를 빼고 써도 붙습니다. |
| `sections` | | ※ 알림 아래, 발행일 위에 넣는 안내 묶음: `[{"title": "< 가정에서 함께 챙겨 주세요 >", "lines": ["1. …", "2. …"]}]`. 소제목은 표 위 제목 모양, 줄은 인사말 모양으로 들어갑니다. 보호자 협조 사항처럼 표에 넣기 긴 내용을 두세 줄로 씁니다. 한 쪽을 넘기지 않게 꼭 필요할 때만 씁니다. |
| `masthead` | | 머리말 오른쪽 칸: `{"phones": ["교무실 번호", "행정실 번호"], "homepage": "학교 누리집 주소"}`. 학교 대표 번호만 씁니다. 비우면 `[확인 필요]`로 들어가고 정할 것에 나옵니다. 학교 약칭과 학년도(3월부터 새 학년도)는 저절로 들어갑니다. |
| `doc_date` | | 문서 날짜 `2026-11-20`. 발행일 줄과 연도가 없는 날짜의 요일 검사에 씁니다. 비우면 오늘. |
| `issue_date` | | 발행일 줄. 비우면 `2026년 11월    일`(날은 직접 씁니다). |
| `reply` | | 참가 동의서. 없으면 자르는 선부터 아래를 모두 지웁니다. |
| `template` | | 다른 양식 파일. 이름만 쓰면 JSON 옆 → `templates/` 순서로 찾습니다. |
| `page_title` | | 미리보기 아티팩트 이름(2~4낱말). |
| `example` | | `true`면 미리보기에 "예시 자료"라고 표시합니다. |

## 회신서 `reply`

```json
"reply": {
  "title": "2026. 3학년 박물관 체험학습 참가 동의서",
  "pledge": "상기 내용을 확인하고 동의서를 제출합니다.",
  "note": "참가에 동의하지 않는 학생은 학교에서 별도의 계획에 따라 학습을 실시합니다.",
  "consents": ["활동 중 찍은 사진을 학교 누리집과 학급 소식에 싣는 것"],
  "fields": ["건강 특이 사항(알레르기, 복용 약, 멀미 등)"],
  "privacy": {"include": null}
}
```

- 동의서는 학교 승인 양식 그대로입니다: `(  )학년 (  )반 이름` 줄, 참가 동의함·동의하지 않음 표, 확인 문장(`pledge`, 비우면 위 문장), 학생·보호자 이름과 서명 줄, 맨 아래 ※ 알림(`note`, 비우면 줄을 지웁니다). 연락처는 받지 않습니다.
- `title`: 회신서 제목. 직접 입력할 때는 60자 이내로 씁니다.
- `consents`: 참가 말고 따로 묻는 동의. 보호자가 할 일이 늘어나니 선생님이 꼭 필요하다고 할 때만 씁니다. 한 줄에 하나씩 `○ …에 동의합니까?   □ 동의함   □ 동의하지 않음`으로 확인 문장 아래에 들어갑니다. 사진·영상 게시, 물놀이·수영처럼 위험이 따르는 활동, 비용 부담 등에 씁니다.
- `fields`: 보호자가 적어 줄 칸(꼭 필요할 때만). `○ 건강 특이 사항: ____` 모양으로 들어갑니다. 연락처 칸은 만들지 않습니다.
- `privacy.include`
  - `null`: 아직 정하지 않았습니다. 문서에는 넣지 않고, 결과의 `needs_confirmation`과 미리보기 맨 위에 "정할 것"으로 나옵니다.
  - `true`: 동의서 문장 아래에 개인정보 수집·이용 안내와 동의 칸을 넣습니다. `items`, `purpose`, `retention`, `refusal`을 채웁니다. 빈 칸은 `[확인 필요]`로 들어갑니다.
  - `false`: 넣지 않습니다(선생님이 정했을 때만).

## 검사

- **한 쪽 어림:** 양식의 줄 높이로 본문 높이를 어림해 A4 한 쪽을 넘을 것 같으면 `needs_confirmation`에 "한 쪽을 넘을 것 같아요"를 넣습니다. 어림이라 실제 쪽 나눔은 한글에서 확인합니다.

- 날짜 `2026. 12. 9.(수)`의 요일, 같은 해의 짧은 날짜 `12. 10.(목)`의 요일
- 회신 기한이 행사 날짜보다 앞서는지
- 만든 파일의 열림·자리표시자·요일(`scripts/gate.py`)
