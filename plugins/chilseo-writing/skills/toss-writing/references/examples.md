# 상황별 토스라이팅 예시

교사용·수업용 웹 앱 기준 예시다. 다른 분야에도 같은 방식으로 바꿔 쓴다.

## 문장 규칙 5가지

| 규칙 | 고치기 전 | 고친 뒤 |
|---|---|---|
| 해요체 | 저장되었습니다. | 저장했어요. |
| 능동형 | 모둠이 배정됐어요. | 모둠을 배정했어요. |
| 능동형(~된 빼기) | 선택된 학생 3명 | 선택한 학생 3명 |
| 능동형(동사 바꾸기) | 결과가 학생에게 공유돼요. | 학생에게 결과를 보여 줘요. |
| 긍정형 | 학생이 부족해서 배정할 수 없어요. | 학생을 2명 이상 넣으면 배정할 수 있어요. |
| 긍정형(일부 기능) | 이 기기에서는 백업 기능을 쓸 수 없어요. | 백업은 파일로 내려받아 할 수 있어요. |
| 캐주얼한 경어 | 모둠을 다시 섞으시겠어요? | 모둠을 다시 섞을까요? |
| 캐주얼한 경어 | 선생님께 알림을 보내 드려요. | 선생님에게 알림을 보내요. |
| 캐주얼한 경어(주어 바꾸기) | 명단 파일을 가지고 계시나요? | 명단 파일이 있나요? |
| 명사 나열 풀기 | 명단 등록 완료 | 명단을 등록했어요 |
| 명사 나열 풀기 | 용량 초과로 저장 실패 | 용량이 꽉 차서 저장하지 못했어요 |
| 되어요 → 돼요 | 자동으로 저장되어요. | 자동으로 저장돼요. |

## 예외가 맞는 경우 (고치지 않는다)

| 문구 | 그대로 두는 이유 |
|---|---|
| 학생 정보는 이 기기에만 저장돼요. | 사용자를 안심시키는 수동형 |
| 학생 이름은 다른 곳으로 보내지 않아요. | 사용자를 안심시키는 부정형 |
| 지우면 모둠 기록도 함께 삭제돼요. | 사용자 행동의 결과를 알리는 수동형 |
| 학생 화면에서는 명단을 바꿀 수 없어요. 선생님 화면에서 바꿔 주세요. | 정책상 막힌 기능을 이유와 함께 알리는 부정형 |
| 지난 시간 모둠을 다시 쓰시나요? | 사용자 맥락을 짚어 묻는 경어 |

## 버튼

| 고치기 전 | 고친 뒤 | 이유 |
|---|---|---|
| 확인 | 모둠 배정하기 | 누르면 생길 일을 예측할 수 있다 |
| 제출 | 답 보내기 | 동작을 구체적으로 |
| 삭제 | 명단 지우기 | 무엇이 사라지는지 분명히 |
| 초기화 | 처음부터 다시 하기 | 쉬운 말 |
| 예 / 아니오 | 지우기 / 그대로 두기 | 각 버튼의 결과를 적는다 |
| (대화창) 취소 | 닫기 | "취소"는 하던 작업이 지워진다고 오해할 수 있다 |

## 안내 문구

| 고치기 전 | 고친 뒤 |
|---|---|
| 본 기능은 학생 명단을 기반으로 모둠을 자동 배정하는 기능입니다. 아래 입력창에 학생 이름을 입력하신 후 배정 버튼을 클릭해 주시기 바랍니다. | 학생 이름을 한 줄에 한 명씩 넣고 '모둠 배정하기'를 눌러 주세요. |
| 데이터는 브라우저 로컬스토리지에 저장되며 서버로 전송되지 않습니다. | 이 기기에만 저장되고, 다른 곳으로 보내지 않아요. |
| 타이머 설정 후 시작 버튼을 누르십시오. | 시간을 정하고 '시작하기'를 눌러 주세요. |

## 오류

| 고치기 전 | 고친 뒤 |
|---|---|
| 잘못된 입력입니다. | 숫자만 넣어 주세요. |
| Error: JSON parse failed | 파일을 읽지 못했어요. 이 앱에서 저장한 파일인지 확인해 주세요. |
| 학생 수가 부족하여 배정이 불가능합니다. | 모둠 수보다 학생이 적어요. 모둠 수를 줄여 볼까요? |

## 빈 화면

| 고치기 전 | 고친 뒤 |
|---|---|
| 데이터가 없습니다. | 아직 기록이 없어요. 첫 기록을 남겨 볼까요? |
| 검색 결과 없음 | '○○'에 맞는 결과가 없어요. 다른 낱말로 찾아보세요. |

## 확인창 (되돌릴 수 없는 동작)

- 제목: "명단을 지울까요?"
- 본문: "지우면 다시 되돌릴 수 없어요."
- 버튼: "지우기" / "그대로 두기"

## 완료·알림

| 고치기 전 | 고친 뒤 |
|---|---|
| 저장이 성공적으로 완료되었습니다. | 저장했어요. |
| 백업하지 않으면 모든 데이터가 영구 삭제됩니다! | 백업해 두면 다른 기기에서도 이어 쓸 수 있어요. |

## 학생 화면

- 오답: "틀렸습니다" → "아쉬워요! 한 번 더 해 볼까요?"
- 정답: "정답입니다" → "맞았어요! 잘했어요."
- 시간 종료: "시간 초과" → "시간이 다 됐어요. 여기까지 생각한 것도 좋아요."
- 연령에 맞게 쉬운 낱말을 쓰고, 경쟁·순위를 강조하는 표현은 줄인다.

## 다크패턴 고치기

| 다크패턴 | 고친 흐름 |
|---|---|
| 앱을 열자마자 "사용법을 꼭 읽어 주세요" 팝업이 화면을 가린다 | 바로 쓰는 화면을 보여 주고, 처음 한 번만 화면 위쪽에 닫을 수 있는 안내 줄을 띄운다 |
| 학생이 퀴즈 중 나가려 하면 "정말 포기할 건가요? 😢" 창이 뜬다 | 답을 자동 저장하고 "답을 저장했어요. 다시 들어오면 이어서 풀 수 있어요."를 짧게 보여 준다 |
| 설문 화면에 "제출하기" 버튼만 있다 | "나중에 하기"를 함께 두고, 같은 크기·잘 보이는 색으로 만든다 |
| "결과 보기"를 눌렀더니 다른 기능 홍보 화면이 먼저 뜬다 | 결과를 바로 보여 주고, 홍보는 결과 아래에 작게 둔다 |
| 버튼 위에 "지금 안 하면 손해예요!" | 버튼에 할 일만 쓴다: "백업 파일 내려받기" |
