# 교실 기기 기준

학교에서 웹 앱이 실제로 열리는 기기별 기준이다. 숫자는 출발점으로 쓰고, 실제 기기에서 보고 조정한다.

## 기기별 기준

| 기기 | 화면 크기(CSS px) | 보는 거리 | 본문 글자 | 주의할 점 |
|---|---|---|---|---|
| 전자칠판·TV 투사 | 1920×1080 (확대 배율 때문에 더 작게 잡히기도 함) | 3~8m | 32px 이상, 핵심 숫자·이름은 48px 이상 | 스크롤 없이 한눈에. 옅은 회색 글자와 얇은 글꼴은 멀리서 안 보인다. 대비를 더 높인다 |
| 웨일북·노트북 | 1366×768 ~ 1920×1080 | 50cm | 16px 이상 | 세로 공간이 좁다. 768px 높이에서 주요 버튼이 보이는지 확인 |
| 태블릿 | 세로 768×1024 안팎 | 40cm | 학생용 18px 이상 | 터치. 버튼 48px 이상, 마우스 올리기(hover)에만 기대는 기능을 만들지 않는다 |
| 스마트폰 | 360~430 너비 | 30cm | 16px 이상 | 보호자용 화면(가정통신문 등)일 때 고려 |

## 반응형 기준점

```css
/* 작은 화면부터 쓰고 넓어질 때 덧붙인다 */
@media (min-width: 768px)  { /* 태블릿 */ }
@media (min-width: 1280px) { /* 웨일북·노트북 */ }
```

전자칠판용은 기준점 대신 "크게 띄우기" 모드(전체 화면 + 글자 확대)를 따로 만든다. `document.documentElement.requestFullscreen()`으로 전체 화면을 켜고, 아무 곳이나 누르거나 Esc를 누르면 돌아오게 한다.

## 학생 화면

- 글을 끝까지 읽지 않는다고 생각하고 설계한다. 그림·아이콘·버튼 위치로 할 일을 알게 한다.
- 저학년은 글자를 더 크게(20px 이상), 한 화면 정보를 더 적게 한다.
- 순위, 남은 시간, 빨간 경고처럼 압박을 주는 표시는 꼭 필요할 때만 쓴다.
- 실수해도 쉽게 되돌릴 수 있게 한다(되돌리기 버튼, 자동 저장).

## 교사 화면

- 수업 중에는 한 손, 짧은 시간 안에 쓴다. 자주 쓰는 동작을 첫 화면 가장 큰 버튼으로 둔다.
- 학생이 보는 화면(전자칠판)과 교사만 보는 화면(설정, 명단)을 나눈다. 띄운 화면에 학생 개인정보나 다른 학생 점수가 보이지 않게 한다.

## 실행 환경

- 공모전 심사는 ZIP 안의 `index.html`을 바로 연다. `file://`로 열려도 동작해야 한다.
  - 외부 CDN을 쓰지 않는다. 글꼴, 아이콘, 라이브러리 파일을 함께 넣는다.
  - `fetch()`로 로컬 파일을 읽는 방식은 `file://`에서 막힐 수 있다. 데이터는 JS 파일 안에 넣거나 파일 선택 창으로 받는다.
- 웨일 브라우저에서 꼭 확인한다(크롬 계열이라 대부분 같지만 학교 기기는 웨일이 기본인 경우가 많다).
