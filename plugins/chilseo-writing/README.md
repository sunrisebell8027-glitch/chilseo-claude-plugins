# chilseo-writing: 웹 앱 디자인·문구 스킬 4종

수업용 웹 앱, 학급 도구, 보호자용 신청 화면을 Claude와 만들 때 **보기 좋고, 쓰기 쉽고, 저작권 걱정 없게** 도와주는 스킬 묶음입니다.

| 스킬 | 하는 일 |
|---|---|
| `toss-writing` | 앱의 "핵심 철학"을 먼저 정하고, 버튼·안내·오류 문구를 쉬운 해요체로 씁니다. 사용자를 속이거나 가두는 화면(다크패턴)이 없는지 점검합니다. 문구 검사 스크립트가 들어 있습니다. |
| `toss-design` | 화면 흐름을 행동 단위로 나누고, 한 화면에 한 가지만 하게 설계합니다. 색·글자·여백·접근성, 전자칠판·웨일북·태블릿 화면을 챙깁니다. |
| `krds-design` | 가정통신문·신청서·동의서·공지처럼 공공 서식 성격의 화면을 정부 디자인 시스템(KRDS) 기준으로 만듭니다. |
| `web-assets` | 저작권이 확실한 무료 글꼴·아이콘·CSS를 골라 프로젝트 안에 내려받고, 출처 목록을 만듭니다. 인터넷이 없는 교실에서도 화면이 깨지지 않습니다. |

Claude가 부탁 내용을 보고 알맞은 스킬을 알아서 고릅니다. 보통 `toss-writing`(철학) → `toss-design` 또는 `krds-design`(디자인) → `web-assets`(자료) → `toss-writing`(문구 점검) 순서로 씁니다.

## 설치 3단계

**Claude 앱(채팅 화면)**

1. `toss-writing.zip`, `toss-design.zip`, `krds-design.zip`, `web-assets.zip`을 받습니다(압축을 풀지 않습니다).
2. 설정 → 기능(Capabilities)에서 **코드 실행 및 파일 만들기**를 켭니다.
3. **스킬(Skills)** → **스킬 업로드**로 zip 네 개를 하나씩 올립니다.

**Claude Code**

1. `/plugin marketplace add sunrisebell8027-glitch/chilseo-claude-plugins`
2. `/plugin install chilseo-writing@chilseo-plugins`
3. Claude Code를 다시 시작합니다.

## 첫 부탁 예시

> 우리 반 아침 활동 타이머 웹 앱을 index.html 하나로 만들어 주세요. 전자칠판에서 멀리서도 잘 보이게, 버튼 문구는 쉽게 써 주세요.

> 보호자용 현장체험학습 참가 신청 화면을 KRDS 디자인으로 만들어 주세요. 개인정보 동의 문구도 넣어 주세요.

> 이 앱의 화면 문구를 토스 라이팅 원칙으로 점검해 주세요. (파일 올리기)

## 꼭 알아 두세요

- 토스·KRDS가 **공개한 원칙을 참고해 새로 쓴 비공식 가이드**입니다. 토스(비바리퍼블리카)와 관계없습니다.
- 토스의 글꼴·아이콘·그래픽은 넣지 않고, 쓰지도 않게 안내합니다. 토스 디자인 키트는 앱인토스 밖에서 쓸 수 없기 때문입니다.
- KRDS 자료는 공공저작물이라 출처를 밝히면 쓸 수 있습니다. `web-assets`가 출처 목록을 만들어 줍니다.
- 근거 자료와 참고한 커뮤니티 스킬(모두 MIT)은 각 스킬의 `references/sources.md`에 적어 두었습니다.
- 학생 이름·사진이 담긴 자료를 웹 앱에 넣을 때는 학교의 개인정보 기준을 먼저 확인하세요.
